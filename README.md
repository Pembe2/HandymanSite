# North Beach Repair Website

A responsive, Jobber-ready website using the official Seafoam & Slate brand system.

## Branding

- Deep Slate: `#1E3A4A`
- Seafoam: `#4CB6B2`
- Sand: `#E6D6B8`
- Foam: `#F7F9F8`
- Charcoal: `#2D3336`

The included `logo.svg` contains the compass-and-waves logo treatment.

## Jobber setup

Open `quote.html` and locate the `JOBBER SETUP` placeholder. Replace the placeholder with the full Jobber embed code.

## Before publishing

Replace the placeholder phone number, email address, service area, and any service descriptions that do not match your offerings.
